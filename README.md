CryoAtlas project website: a curated dataset and unified benchmark for cryo-EM atomic model building.

Website: https://oulling.github.io/cryoatlas/

Interactive v1 benchmark: https://oulling.github.io/cryoatlas/explore/

The explorer includes 618 targets, each with five method previews plus the GT protein backbone and a downsampled density preview. Display files retain the v1 map coordinate frame; the browser applies no extra fitting or refinement. Scores come from existing v1 tables. Full datasets and source code are separate resources. Structure previews omit sidechains; density previews are block-averaged to at most 96 voxels per axis and quantized for display. They are not evaluation inputs.
