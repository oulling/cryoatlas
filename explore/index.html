About this visualization

Explore CryoAtlas benchmark targets by overlaying up to two predicted protein models with the curated reference (GT) and experimental cryo-EM density. Each prediction has a distinct color; Selecting Reference (GT) in either model selector shows it in opaque dark gray. The optional GT overlay remains pale; Emphasize reference (GT) makes it clear while keeping both predictions selected. All models share the map coordinate frame. AlphaFold 3 uses a whole-complex USalign alignment to GT, without per-chain fitting.

The default density preview loads quickly. Choose a cropped high-detail view or the original-resolution EMDB map for closer inspection, then adjust density threshold and opacity. Scores below the viewer report existing v1 benchmark results for each selected method. This visualization performs no additional prediction, refinement, or evaluation.
